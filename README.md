# 📝 Notes Manager (Tkinter)

Простое desktop-приложение для создания и управления заметками на Python с использованием `tkinter`.
<img width="396" height="521" alt="image" src="https://github.com/user-attachments/assets/07cf0750-7a35-4a53-8931-4f9fa50b68d2" />

Программа позволяет:

* ➕ добавлять заметки
* 🗑️ удалять выбранные
* 🧹 очищать весь список
* ⌨️ быстро добавлять заметки через Enter

---

## 🚀 Возможности

* Графический интерфейс
* Добавление заметок
* Удаление отдельных заметок
* Полная очистка списка
* Проверка на пустой ввод
* Удобное управление через клавиатуру

---

## ▶️ Запуск программы


---

## 🖥️ Интерфейс программы

После запуска откроется окно:

```text
Менеджер нотаток
```

### Элементы интерфейса

| Элемент             | Назначение                |
| ------------------- | ------------------------- |
| Поле ввода          | ввод новой заметки        |
| ➕ додати нотатку    | добавить заметку          |
| Список заметок      | отображение всех заметок  |
| 🗑️ видалити обране | удалить выбранную заметку |
| 🧹 очистити все     | удалить все заметки       |

---

## 📝 Как пользоваться

### 1. Добавление заметки

Введите текст в поле:

```text
Купить молоко
```

Затем:

* нажмите кнопку `➕ додати нотатку`
  или
* нажмите клавишу `Enter`

Заметка появится в списке.

---

## 🗑️ Удаление заметки

1. Выберите заметку в списке.
2. Нажмите:

```text
🗑️ видалити обране
```

Выбранная заметка будет удалена.

---

## 🧹 Очистка всех заметок

Нажмите:

```text
🧹 очистити все
```

После этого программа спросит подтверждение:

```text
Ви впевнені, що хочете видалити всі нотатки?
```

Если нажать **Yes**, все заметки удалятся.

---

## ⚠️ Проверка ошибок

### Пустая заметка

Если попытаться добавить пустой текст:

```python
if text:
```

появится сообщение:

```text
Не можна додати порожню нотатку!
```

---

### Удаление без выбора

Если пользователь не выбрал заметку:

```text
Будь ласка, спочатку оберіть нотатку зі списку
```

## 🔧 Основные методы

| Метод           | Описание                  |
| --------------- | ------------------------- |
| `add_note()`    | добавляет новую заметку   |
| `delete_note()` | удаляет выбранную заметку |
| `clear_all()`   | очищает весь список       |
| `__init__()`    | создаёт интерфейс         |

---

## ⌨️ Работа Enter

Программа поддерживает быстрое добавление заметок через клавишу Enter:

```python
self.entry.bind('<Return>', lambda event: self.add_note())
```

То есть:

* пользователь нажимает Enter
* автоматически вызывается `add_note()`
